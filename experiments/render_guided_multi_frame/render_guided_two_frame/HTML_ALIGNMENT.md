# 两帧实现与 HTML 对照

| HTML | 两帧代码 |
| --- | --- |
| §2 未知量 | PairwiseModel 优化有效运动 H_k 与 Gaussian 归属 q_ik；固定 Gaussian 几何。 |
| §3–4 表示与双目初始化 | make_gaussians 用米制深度与颜色初始化；默认逐像素各向同性投影尺度，与旧流程一致。可选 surface_aligned 模式由局部深度估计切向、法向和 footprint；协方差随刚体运动旋转。 |
| §5 稀疏证据 | SuperPoint/LightGlue 跨帧匹配；lift 由两帧深度生成 3D–3D anchor。 |
| §6 初始运动 | discover 使用顺序 RANSAC/SVD；anchor_probabilities 按残差计算 q_jk。联合优化期间根据当前 H_k 重新计算 q_jk。 |
| §7 Gaussian 归属 | 按 3D 距离、颜色、深度传播；稀疏初始化、渲染及图平滑共同更新 q_ik；额外一致性项默认关闭。 |
| §8 条件渲染 | 每个 (i,k) 使用 H_k μ_i、R_k Σ_i R_k^T、q_ik α_i，统一 alpha 合成与温度退火。 |
| §9 两帧目标 | 几何 mixture、RGB L1/SSIM、双目置信度加权 robust 深度、熵、图平滑；离散结构提案含分量数惩罚。 |
| §10 反馈 | 残差、归属梯度和运动 J^T r 梯度；按 HTML 的 patch 均值公式用未经归一化的梯度选区，软归属权重参与投影；局部降低特征阈值、增加点数。可解释 anchor 附着；未解释 anchor 仅在新运动验收后进入保留状态，循环执行。 |
| §11 分量管理 | birth、split、merge 和低支持 prune 均有候选及验收；长期轨迹/生命周期条件属于多帧状态。 |
| §12 参考运动 | 根据几何支持、图像覆盖和 3D 范围选参考，输出 H_0 及其逆对应的相对相机位姿。 |
| §16–17 算法和实验 | strict_two_frame.run 执行全部两帧流程；配置支持关闭反馈、梯度和各结构操作，支持受控漏检。 |

§13–15 的持续地图、滑窗和在线 SLAM 前后端由用户明确排除。预计算 IGEV 深度文件没有原生置信度，故 c_D(u) 由真实左右图的光度一致性得到。运动梯度从可微渲染对刚体变换的雅可比计算，默认选区分数保持 HTML §10.3 的归属梯度形式。
